A simple food ordering application where users can browse through different food, view their details, and add them to the cart. The app features a dynamic shopping cart where users can adjust the quantity of pizzas and see the total price.
The project dynamically fetches pizza data and displays it in a card-based UI.

⚠️ **Important:** Currently, the images for the food items are not showing because the external JSON data source is under construction. Once the data is updated and fully functional, the images will appear correctly. Thank you for your understanding!

## Features
- Displays food items in a responsive, card-based gallery with images and descriptions.
- Fetches food data from external JSON data source and dynamically generates content.
- Includes a "Select" button for each food item.
- Add food to the cart and view a popup with more details.
- See the total price and number of items in the cart in real-time.
- Users can view, update, and remove items from the cart.
- Responsive design, works well on both desktop and mobile.
  
## Technologies Used
**HTML:** Structure of the application. <br />

**Tailwind CSS:** For responsive and modern styling. <br />

**JavaScript (ES6):** For dynamic functionality, such as adding to the cart and calculating totals. <br />

**Fetch API:** To retrieve food data from a JSON file. <br />

**JSON:** To store food information (used as a mock database).
